# Compliance approach

This platform is **not** certified or audited. Controls are **inspired by** financial
regulations and mapped to them for traceability ([ADR 0019](../adr/0019-treat-regulations-as-reference-frameworks.md)).

| Document | Purpose |
|---|---|
| [control-matrix.md](control-matrix.md) | Reference → control → implementation → evidence |

Rules for this folder:

- Never write "compliant with"; write "maps to" or "inspired by".
- Any quoted retention period or requirement cites its source clause.
- A control without evidence is marked `planned`, not `implemented`.
